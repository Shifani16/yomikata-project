# yomikata-project

YomiKata is a web application designed to help to learn how to read and understand Japanese text. Provides an easier feature
where all we need to do is to input the Japanase text to know what it mean, how the kanji read, and what that specific kanji mean. The application aims to enhance language learning by offering a practical tool for reading practice.

Created using React and TypeScript, kanji-furigana library by Kuroshiro, and JMDict for word translation and meaning. For contact, please refer me to my personal page.
